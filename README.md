# Prótesis Viva

App educativa en **Unity 6 (URP)** para **Android** que muestra de forma interactiva una prótesis de mano transradial (`Protesis_Mano_LODs`, 3 LOD, 66 piezas por nivel). Proyecto para el curso de Gráficos.

## Funciones
- **F1 · Vibración al agarrar firme:** el sensor de presión de las yemas brilla y el motor de vibración se activa.
- **F2 · Fuerza ajustable:** una perilla se desliza por un riel (Suave, Medio, Fuerte) y limita cuánto cierra la mano.
- **F3 · Alerta de objeto caliente:** si el sensor pasa de 50 °C se enciende una luz roja; se apaga sola al soltar y enfriarse.
- Cables amarillos F2 que se deforman con los dedos.
- 3 vistas de cámara (general, detalle, Rayos X) y modo Día/Noche.
- **Cinemáticas:** Saludar, Amor y paz y Explicar (banners con líneas que señalan cada parte).
- **Escenario:** la mano en una vitrina dentro de una tienda con neones y focos.
